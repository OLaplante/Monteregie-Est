LES PAGES SE REFONT TOUTES SEULES APRÈS UNE MODIFICATION DE data.json
----------------------------------------------------------------------
**data.json est la seule source de vérité.** Les pages ci-dessus en sont fabriquées, et
depuis le 19 août 2026 c'est GitHub qui s'en charge automatiquement :

    on modifie data.json  →  GitHub régénère les pages  →  le site est à jour
                             (une à deux minutes plus tard)

Il n'y a donc RIEN à faire de plus après avoir modifié data.json. Pas de zip à demander, pas de
fichier à redéposer. On modifie data.json comme d'habitude (voir la section suivante), on
enregistre, et c'est fini.

Pour voir où ça en est : onglet « Actions » du dépôt GitHub. Une pastille verte = les pages ont
été refaites. Une pastille rouge = quelque chose a été refusé (voir plus bas).

CE QUI SE PASSE EXACTEMENT
Le robot (fichier .github/workflows/generer-pages-seo.yml) relance le générateur et publie
automatiquement les pages à jour après chaque modification de data.json (une à deux minutes).

Ce que le générateur protège tout seul, sans qu'on ait à y penser :
- les notes personnelles et les courriels de recrutement ne sortent jamais sur le site public ;
- une fiche « visible: false » n'apparaît nulle part ;
- l'adresse web d'une clinique NE CHANGE PAS si on corrige son nom (elle est mémorisée dans
  scripts/slugs.json — ne pas supprimer ce fichier, sinon les adresses déjà connues de Google
  seraient perdues) ;
- une fiche trop peu remplie (moins de 5 renseignements) reçoit sa page, mais on ne la propose
  pas à Google tant qu'elle reste presque vide ; elle y entre toute seule une fois complétée.

La commande, pour information, si on veut la lancer sur son propre ordinateur :
   node scripts/generer-pages-seo.js


METTRE À JOUR UNE CLINIQUE (sans toucher au code)
--------------------------------------------------
1. Sur GitHub : dépôt Map -> data.json -> crayon (modifier).
2. Changer la valeur voulue (téléphone, horaire, site, etc.).
   - Texte entre guillemets droits "..."
   - Virgule entre les éléments, PAS de virgule après le dernier d'une liste.
3. Commit. Le robot inscrit automatiquement la date du jour dans "miseAJour"
   selon le fuseau de Montréal, puis régénère les pages.
4. La nouvelle version s'affiche à la prochaine ouverture.
   (Si data.json est invalide, l'app affiche « Données indisponibles » :
    il suffit de corriger la virgule fautive.)

   Il n'est PAS nécessaire de changer la version du cache pour data.json :
   ce fichier est toujours rechargé depuis le réseau.


DEUX CHAMPS À NE PAS CONFONDRE
-------------------------------
- "infos"  : information publique sur la clinique. C'est ici qu'on écrit.
- "notes"  : réservé aux notes personnelles de chaque utilisateur, qui sont
             conservées sur son appareil. Tout ce qu'on écrirait ici serait
             effacé à l'affichage. Laisser vide.


AJOUTER UNE CLINIQUE
--------------------
Copier un bloc complet entre accolades { ... }, le coller à la fin de la liste
(en ajoutant une virgule après le bloc précédent), puis :
  - donner un "id" qui n'existe pas déjà ;
  - remplir au minimum : nom, type, region, rls, lat, lng.
La latitude et la longitude s'obtiennent sur Google Maps : clic droit sur le
point -> les deux nombres apparaissent en haut du menu.


FORCER UNE MISE À JOUR APRÈS UN CHANGEMENT DE CODE
---------------------------------------------------
Seulement si on a modifié index.html, sw.js ou les icônes.
Dans sw.js, augmenter le numéro de version du cache :
   const CACHE = 'ptem-2027-v28';   ->   'ptem-2027-v29'
puis re-téléverser sw.js. Sans cela, les personnes qui ont déjà ouvert
l'application continueront de voir l'ancienne version.
(Depuis le 19 août 2026, il n'y a PLUS de liste de pages à tenir à jour dans
sw.js : le fichier reconnaît tout seul que seule la page d'accueil appartient
à l'application. On peut donc ajouter autant de pages de contenu qu'on veut
sans jamais toucher à sw.js.)


INSTALLER L'APPLICATION
-----------------------
- Android / ordinateur : bouton « Installer l'application » dans l'app,
  ou menu du navigateur -> « Installer ».
- iPhone (Safari) : bouton Partager -> « Sur l'écran d'accueil ».


PARTAGER LE LIEN
----------------
Le bouton rond à côté du « i », en haut à droite, ouvre le partage du
téléphone. Sur ordinateur, il copie l'adresse dans le presse-papiers.
